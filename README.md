# PROJECT OVERVIEW

Managing personal finances effectively requires clear visibility into spending habits. **Bugdeto** offers a streamlined, intuitive interface that simplifies financial management. It empowers users to take control of their money by categorizing expenses, tracking income streams, managing recurring monthly costs, and monitoring overall savings progress in real time.

# FEATURES

- **Income & Expense Tracking:** Log daily income and expenses with detailed categories.
- **Monthly Budget Planning:** Set spending limits and manage monthly financial targets.
- **Savings Management:** Track contributions toward short-term and long-term financial goals.
- **Real-Time Database:** Seamless synchronization of financial records across devices powered by Firebase.
- **Responsive UI:** Clean, intuitive user interface designed with Material UI for mobile and desktop screens.
